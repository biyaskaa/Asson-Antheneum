# Asson-Antheneum

**Asson-Antheneum** — сайт-библиотека, где собраны переводы произведений русских и зарубежных авторов на карачаево-балкарский язык. Проект помогает сохранять и развивать родной язык и делает мировую литературу доступной на нём.

*Online library of Russian and world literature translated into the Karachay-Balkar language.*

🌐 **Сайт:** [biyaskaa.github.io/Asson-Antheneum](https://biyaskaa.github.io/Asson-Antheneum/) — читалка онлайн и все PDF.

---

## 📖 О проекте

Карачаево-балкарский язык — родной язык карачаевцев и балкарцев. Художественной литературы, доступной на нём, пока немного, особенно переводной классики. Asson-Antheneum собирает такие переводы в одном месте, чтобы:

- читать любимые книги на родном языке;
- поддерживать живую литературную речь;
- дать материал тем, кто изучает язык.

## 🤝 Как помочь

- **Переводить.** Если вы владеете карачаево-балкарским и хотите перевести произведение, откройте [Issue](../../issues) с названием книги.
- **Вычитывать.** Нашли ошибку или неудачную формулировку — напишите в Issues или пришлите Pull Request.
- **Рассказывать.** Поделитесь проектом с теми, кому он может быть интересен.

## 🗂 Устройство сайта

Статический сайт для GitHub Pages, без сборки:

- `index.html` — главная с бумажной анимацией
- `library.html` — скачать PDF
- `read.html` — онлайн-читалка (PDF.js), `read.html?book=<slug>` открывает конкретную книгу
- `data/books.js` — список книг: чтобы добавить новую, положите PDF в `pdf/` и допишите строку
